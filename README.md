# Laboratoire — Programmation par flot (Streams) — IFT359

Exercices pratiques sur la programmation par flot.

## Prérequis

- [Node.js](https://nodejs.org/) (version LTS recommandée)

## Installation

Une fois Node.js installé, ouvrez un terminal à la racine du projet et exécutez la commande suivante pour installer les dépendances :

```bash
npm install
```

## Commandes disponibles

| Commande             | Description                                                                                |
| :------------------- | :----------------------------------------------------------------------------------------- |
| `npm run test`       | Exécute les tests unitaires une fois.                                                      |
| `npm run test:watch` | Exécute les tests en mode surveillance (rechargement automatique à chaque sauvegarde).     |
| `npm run build`      | Vérifie les types et compile le projet TypeScript vers JavaScript dans le dossier `dist/`. |
| `npm run format`     | Formate le code avec Prettier.                                                             |
| `npm run clean`      | Supprime le dossier `dist/` contenant les fichiers compilés.                               |
